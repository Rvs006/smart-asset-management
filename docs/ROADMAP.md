## Build Philosophy
Reuse the Smart Commissioning Tool's stack and GUI verbatim (React 19 + Vite + react-router + TanStack Query; FastAPI + SQLite local profile; import SCT's two CSS files). Build the magic-moment path first — a real import that surfaces cross-trade duplicates and invalid references — then widen. Every phase leaves a runnable app. Project metadata is schema-as-data + per-asset JSON, never a table per project. Validate on the server; the grid reflects it.

- [x] **TASK-011** — Trades API + seed helper.
  Files: `backend/app/api/routes/trades.py`, `backend/app/seed.py`
  Notes: `GET/POST /trades`; `seed.py` builds a demo project (references + 171 schema + trades + a few dozen assets incl. a deliberate cross-trade duplicate Instance Name and an invalid level) so the magic moment works out of the box. Verify: `python -m app.seed` creates the demo project.
- [x] **TASK-012** — Validation engine.
  Files: `backend/app/validation.py`
  Notes: pure function `validate_project(conn, project_id) -> [ValidationIssue]`. Rules: (a) cross-trade duplicate `instance_name` (error, project-wide); (b) invalid reference for reference-typed fields (level/space/system/zone/equipment-type not in ReferenceValue); (c) missing mandatory (required=yes and blank); (d) conditional-required via `conditional_expr` (e.g. `QR Size` required when `QR Required`=Yes); (e) format (unique-local-number digit count; basic IP/MAC shape). Each issue records asset_id, field_key, severity, rule, message, expected. Persist to ValidationIssue (replace prior unresolved). Include a `demo()`/assert self-check. Verify: run against seed → duplicate + invalid-level + missing-QR-size issues appear.
